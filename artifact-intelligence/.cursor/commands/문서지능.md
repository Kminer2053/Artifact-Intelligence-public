## Objective
`artifact-intelligence` MCP 도구로 대한민국 공공기관 문서(1페이지·풀버전 보고서, 시행문, 규정, 보도자료, 발표 슬라이드)를 **사람과 단계별로 함께** 만든다. 백지에서 뽑아 던지지 말고, 아래 **⏸** 에서 멈춰 사용자 확인·수정의견·진행 판단을 받은 뒤 다음으로 간다. `.cursor/rules/artifact-intelligence.mdc` 규칙을 따른다.

## Requirements
- **0. 버전 확인** — 클론 `plugin.json` 과 공개 마켓 버전을 대조해 뒤처졌으면 갱신을 먼저 안내(git pull).
- **1. 접수** — "의도 한 줄 + 자료"(텍스트·파일 첨부)를 받는다. 독자·목적·상황 확정, 모호하면 되묻기.
- **2. 판정 ⏸** — `판정`(detect)로 장르·유형을 가려 **사용자에게 보여주고 "이대로 진행할까요?" 확인**. 점수가 갈리면 고르게 한다.
- **3. 빌드플랜 설계 ⏸** — `설계지시문내기`(composeplan)로 구성 계획을 짜 `플랜저장`(saveplan)→plan_id, **사용자에게 보여 `플랜승인`(approveplan) '승인'** 을 받는다. **승인 없으면 새문서·조립이 게이트에 막힌다.**
- **4~5. 초안·조립·검사** — 승인된 plan_id 를 doc 에 넣어 `프롬프트조립`(compose) 지침대로 초안을 쓰고, `새문서`(new)로 등록·조립한 뒤 `문체검사`·`조판게이트`·`지어냈나` 3중 검사를 통과시킨다.
- **6. 편집기 ⏸ (핵심)** — 검사 통과 후 파일을 바로 뽑지 말고, **`편집기열기`(editor · 인자 key)로 편집 화면을 사용자의 실제 브라우저에서 연다**(로컬 편집기 서버 127.0.0.1 을 잠깐 띄운다). 이래야 저장=정본 즉시 반영·되돌림 지점(이력)·AI 다시쓰기가 다 산다. 자동 열기가 안 되면 op 가 준 URL 을 사용자에게 전한다. 「AI에게 고쳐달라」 지시는 "고쳐놨어" 시 `역추적`(backtrace) scan→adopt 로 반영. "이대로 좋다" 전엔 내보내지 않는다.
- **7. 내보내기 ⏸** — 승인 후에만 `내보내기`(export). **모든 형식을 한 번에** 받으려면 형식="전부"(HTML·PDF·HWPX·MD·JSON, 슬라이드는 HTML·PDF·PPTX·MD·JSON).

자료에 없는 수치·이름은 지어내지 말고, 유형이 요구하는 입력이 비면 되묻는다.
