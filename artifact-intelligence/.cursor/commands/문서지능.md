## Objective
`artifact-intelligence` MCP 도구로 대한민국 공공기관 문서(1페이지·풀버전 보고서, 시행문, 규정, 보도자료, 발표 슬라이드)를 만든다. 진행 방식은 둘이다 — **바로 완성**(검수 없이 끝까지, 확인할 곳은 끝 보고에 모음) / **함께 검수**(아래 **⏸** 에서 멈춰 사용자 확인·수정의견·진행 판단을 받은 뒤 다음으로 감). `.cursor/rules/artifact-intelligence.mdc` 규칙을 따른다.

## Requirements
- **0. 버전 확인** — 클론 `plugin.json` 과 공개 마켓 버전을 대조해 뒤처졌으면 갱신을 먼저 안내(git pull).
- **0-1. 방식 정하기** — 방식은 에이전트가 대화를 읽고 정해 `작업방식`(workmode — MCP 인자 decision=보기, work_mode=정한 방식(못 정했으면 비움), request=요청 한 줄)에 싣는다(넘긴 방식→이 대화에서 정한 방식→저장된 선택; 값.힌트는 참고일 뿐). 셋 다 없으면 그때 한 번만 묻고, 답도 에이전트가 읽어 work_mode 에 싣는다('앞으로도 이대로'면 decision=저장, 저장은 work_mode 필수). **바로 완성**이면 아래 ⏸ 에서 멈추지 않는다: 판정(장르는 요청을 읽고 에이전트가 정한다 — 대응표: 보도자료·보도·언론 배포 → `press` · 공문·시행문·협조 요청·안내 공문 → `gongmun` · 규정·내규·지침·규칙·요강·운영기준 → `regulation` · 발표·슬라이드·PPT·프레젠테이션·설명회 자료 → `slides` · 풀버전·상세 보고서·여러 쪽 보고 → `fullreport` · 1쪽·한 장·요약 보고·보고서(말이 없으면) → `samples`; 둘 이상이면 목적어(만들 문서), 주제로 쓰인 말('보도 계획을 보고')은 빼고, 말이 없으면 내용으로; detect 점수는 1페이지 보고서 유형 고르기에만 쓰고, 1위가 약하면 요청을 읽어 상위 3개 가운데 고름) → `플랜승인`을 에이전트가 직접(코멘트 '바로 완성') → `새문서`(검사 true, 원문 — 자료가 없으면 요청 글을 원문으로) → 걸린 검사를 최대 3회 스스로 고침(못 넘으면 내보내지 않고 알림) → `내보내기`(말이 없으면 A4 pdf·hwpx, 슬라이드 pdf·pptx) → 끝 보고(파일 절대 경로·요지·확인할 것·"편집기 열어줘" 안내). 아래 1~7 의 ⏸ 는 **함께 검수** 때만.
- **1. 접수** — "의도 한 줄 + 자료"(텍스트·파일 첨부)를 받는다. 독자·목적·상황 확정, 모호하면 되묻기.
- **2. 판정 ⏸** — 장르는 위 대응표로 정하고, 1페이지 보고서면 `판정`(detect) 점수로 보고목적 유형을 골라 **사용자에게 보여주고 "이대로 진행할까요?" 확인**. 점수가 갈리면 고르게 한다.
- **3. 빌드플랜 설계 ⏸** — `설계지시문내기`(composeplan)로 구성 계획을 짜 `플랜저장`(saveplan)→plan_id, **사용자에게 보여 `플랜승인`(approveplan) '승인'** 을 받는다. **승인 없으면 새문서·조립이 게이트에 막힌다.**
- **4~5. 초안·조립·검사** — 승인된 plan_id 를 doc 에 넣어 `프롬프트조립`(compose) 지침대로 초안을 쓰고, `새문서`(new)로 등록·조립한 뒤 `문체검사`·`조판게이트`·`지어냈나` 3중 검사를 통과시킨다.
- **6. 편집기 ⏸ (핵심)** — 검사 통과 후 파일을 바로 뽑지 말고, **`편집기열기`(editor · 인자 key)로 편집 화면을 사용자의 실제 브라우저에서 연다**(로컬 편집기 서버 127.0.0.1 을 잠깐 띄운다). 이래야 저장=정본 즉시 반영·되돌림 지점(이력)·AI 다시쓰기가 다 산다. 자동 열기가 안 되면 op 가 준 URL 을 사용자에게 전한다. 「AI에게 고쳐달라」 지시는 "고쳐놨어" 시 1페이지 보고서는 `역추적`(backtrace) scan→adopt, 그 밖 장르는 `이력`(history)의 대기 지시를 읽어 고친 뒤 `저장`(save)으로 반영. "이대로 좋다" 전엔 내보내지 않는다.
- **7. 내보내기 ⏸** — 승인 후에만 `내보내기`(export). **모든 형식을 한 번에** 받으려면 형식="전부"(HTML·PDF·HWPX·MD·JSON, 슬라이드는 HTML·PDF·PPTX·MD·JSON).

자료에 없는 수치·이름은 지어내지 말고(모르는 값은 반드시 ○○ 한 꼴로 비운다 — 〇〇·OO·XX·[ ]·빈 밑줄 같은 다른 꼴 금지), 유형이 요구하는 입력이 비면 함께 검수는 되묻고 바로 완성은 ○○로 비워 끝 보고에 올린다(기본값으로도 풀 수 없을 때만 묻는다).
